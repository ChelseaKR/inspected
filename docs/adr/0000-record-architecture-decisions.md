# 0. Record architecture decisions

Date: 2026-08-17

## Status

Accepted.

## Context

The decisions that matter in this project are not about frameworks. They are about what
gets counted, what gets refused, and what does not get published at all. Those are the
decisions a reader needs to be able to argue with, and they are invisible in a diff.

## Decision

Record them here, one file each, in the Nygard format: context, decision, consequences.
An ADR is written when a decision changes what a published number means or when it rules
something out of scope. An ADR is not superseded by deleting it.

## Consequences

The log is short on purpose. Implementation choices that a reader could rederive from the
code do not get one.
