# Outreach drafts

Material addressed to somebody outside this project. Every document here is a
**draft: written, reviewed against the published figures, and not yet sent**. Nothing
here has gone to anybody, and nobody outside this project has read any of it. When one
is sent, its date moves into `PROVENANCE.md` next to the outcome, whatever that outcome
is.

Two letters to the California Energy Commission, which publishes the boundary layers:

- `cec-overlap-letter.md`: the overlap finding, which the publisher's own metadata
  invites feedback on.
- `cec-type-field-request.md`: a records request for the meaning of the `Type` values,
  which nothing published by the party that uses them currently defines.

One packet for a domain reviewer, who has not been found:

- `inclusion-rule-review-packet.md`: the bounded question behind roadmap item 3.3, which
  is whether the publisher's classification of each of the 24 outlines that hold records
  is correct. It carries the twenty-four names with their published `Type` values, what
  the inclusion rule does, what the alternatives were already measured to be worth, and
  what a finding would do, which is become a new sensitivity row rather than an edit to
  the rule.

Recipient addresses are deliberately left as placeholders until sending, so no stale
address is committed as if it were current.
